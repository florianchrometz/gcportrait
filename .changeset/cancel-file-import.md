Export and snapshot files you import, on the Connect page's export card or on the Snapshots page, can now be cancelled while they are read: "Cancel" under the progress bar stops reading them, stores nothing and says "Cancelled. Nothing was stored.", as "Pull now" does. Leaving the page before the import ends cancels it the same way, so no snapshot is stored after you have gone without you knowing.
